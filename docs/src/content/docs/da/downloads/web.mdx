## Versioner

De vigtigste og forhåndsvisning (udvikler) versioner af Flow er ikke de samme som de stabile og natlige versioner.
De er ikke direkte forbundet med en udgivelse. De opdateres, så snart en ny forpligtelse bliver skubbet til lageret.
